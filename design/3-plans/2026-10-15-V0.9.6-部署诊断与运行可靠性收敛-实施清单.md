## 工作包

### WP1 BUG-843：access review 探测口径修正

原则：**不自动发送 POST**；证据不足报「不确定」；保留真实错位检测。

1. [ ] 失败测试：GET 405/404/422 不构成 mismatch 证据（405=路由存在但方法不符，404 无信息量）；
   现网三例形态（POST 端点、`${af}${e}`/`API+'...'` 拼接）不再误报。
2. [ ] 删除/收紧 probable 分支（`access.py:1175-1184`）：「带前缀 JSON 404」不再推出「绝对路径」。
3. [ ] 常量折叠：抽取 API 路径时识别 `const X="<base>"` 与 `X+'/api/...'`、`${X}${e}` 拼接形态，
   折叠为带前缀真实路径再探测（复用 S2-06 route_prefix 思路，尽力而为）。
4. [ ] ApiPathFinding 增加 `uncertain` 分级；证据不足时报告「不确定」而非 mismatch。
5. [ ] 反向用例：真实错位（绝对路径 200 且带前缀 404 的资源形态、显式绝对 fetch）仍能检出。
6. [ ] 三实例复验（现网只读）：prd-review-v035 / funasr-workbench / patent-disclosure 误报消除。

### WP2 BUG-793：收窄 --ignore-scripts

1. [ ] 失败测试：根 package.json 带 `postinstall: node-gyp rebuild` 类原生构建脚本时**不**追加
   `--ignore-scripts`（追加会装不起来）；带已知宿主环境脚本（ensure-*-mirror 类）时仍追加。
2. [ ] 实现：白名单正则（mirror/registry 配置类脚本名与内容特征）之外不追加；manifest 保留用户
   手改 `entry.install` 的既有语义（BUG-787/788 不回退）。

### WP3 BUG-794：admin 端口归属诊断（不自动切换）

1. [ ] doctor 新增（或扩展）检查：登记的 admin 端口被外部进程长期占用时给出 WARN + 占用者线索
   （lsof/ps 归属）与处置建议；不做自动换端口、不动运行中的 Caddy。
2. [ ] 回归：被占用/空闲/归属本工作区三态；缺 lsof 时降级为「无法确认归属」。

### WP4 IMP-066：Flask/Django 生产服务器模板（DEV-162）

按 2609 §6 已拍板方案（066.a~066.g）与 WBS 066.01~066.07 执行：命令优先级（显式命令 > 已声明生产
服务器 > 可证明 WSGI 生成命令 > 开发服务器 fallback）、唯一入口推断（Flask `module:app`/工厂唯一、
Django 唯一 `*/wsgi.py`）、Gunicorn 平台依赖分层安装（不回写用户依赖文件）、低配参数（单 worker、
小线程、绑 0.0.0.0:internalPort）、fallback 三处同源警告（manifest 诊断/管理页/doctor）、存量仅
rebuild 重生成。真实 Docker 验收：Flask 直 app/工厂、Django 单 wsgi、多入口 fallback、显式 ASGI 保留。

### WP5 IMP-067：nginx 收敛为兼容读取（DEV-163）

按 2609 §7 已拍板方案（067.a~067.f）与 WBS 067.01~067.07 执行：新写入（Config/CLI Choice/init/
setup/生成器）仅 caddy|builtin；`load_config()` 预校验层把旧 YAML 的 nginx 映射 builtin（fail-closed
其余非法值，单进程一次警告，load 不改文件）；updater 迁移阶段备份+原子写回 builtin、失败保留原文件、
幂等；迁移后清理运行时 nginx 特判；文档/示例/skills 去「nginx 可选」表述；Full 档兼容边界回归。

### WP6 #61 检查部分：前端产物时效性分级检查（DEV-164）

原则：**只告警，不自动构建**；分级证据；与别名资源检查相互独立。

1. [ ] 统一检查模块（供扫描、导入更新、同步重建、doctor 共用）：
   - **确证陈旧**：本工作区留有构建时源码指纹（frontendsBuild 记录）且与当前前端源不一致；
   - **疑似陈旧**：无指纹，仅源码 mtime 晚于产物（提示词注明「疑似」，不用哈希比新旧）；
   - **无法判断**：源码不可见 / 跨仓关联不明（backend/static 布局但前端目录不在导入树内）。
2. [ ] 接入点：`lwa doctor`（WARN 级）、import --update / rebuild --sync 输出提示、扫描结果诊断字段。
3. [ ] base 配错与产物陈旧分开报告：前者走既有别名资源检查，不混入时效性结论。
4. [ ] 回归：确证/疑似/无法判断/干净四态；#61 在检查部分交付后仍保持 OPEN（预构建待做）。
