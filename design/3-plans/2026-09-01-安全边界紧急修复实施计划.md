# 安全边界紧急修复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task.

**Goal:** 以最小兼容改动修复命令注入、端口误分配、Compose volume 结构注入和安全审计漏项。

**Architecture:** 在不取消现有 hooks、workspace 和端口复用能力的前提下，把用户可控值在最靠近生成点的边界规范化。安全审计保留现有 finding code 和分级，补足明确的高危模式。

**Tech Stack:** Python 3.13、Pydantic、PyYAML、pytest、ruff、mypy

---
