# WSL 第三批：N10-3 实机续验与文档收口

日期：2026-10-22。范围为已具备的 Win10 NAT 组合及用户文档。Win11 mirrored 按用户安排由另一环境的 agent 并行验收，其本机验证与独立 LAN 负向报告已同步到共享目录并核对（CHK-462/463、DOC-217）；本记录保留 N10-3 的独立范围。

## 环境和取证方式

- 源码基线：`8e4f99c`（V0.9.12-Build5406-20261022），包含本地尚未提交的 BUG-949/950 修复。源码归档和差异指纹保存在本地检查点。
- Windows 10 22H2，完整版本 `10.0.19045.6456`；WSL 架构为 WSL2，软件包 `3.0.3.0`；Debian 13.7，运行态 `nat`。
- Docker Engine 29.7.2、Compose 5.5.0 可用。本轮仅核对现状，未降级或重复执行容器 Eval；不作为 CHK-439 最低版本验收。
- 独立源码快照、用户级测试目录、专用实例及管理/网关端口；复用已有 Python 依赖和 Caddy，不改已有源码安装、业务配置、Windows 网络、系统信任或自启。
- 三类观察位置分别留证：Debian 内、Windows localhost（含按 Windows IP 校验证书但连接到 localhost 的测试）、独立物理 macOS 客户端直接访问 Windows LAN 入口。独立 LAN 阶段没有使用 SSH 隧道；另做的真实浏览器交互通过临时仅回环 SSH 通道访问样例，单列为组件验证，不计 LAN 可达性。

## 本轮已执行结果

| 检查 | 结果 | 可说明的范围 |
| --- | --- | --- |
| 中文 Windows portproxy | 两条既有 SSH 转发均可见，网页测试端口没有对应规则 | BUG-943 后真实解码与规则读取已复验；不再把空表当证据 |
| HTTP 页面/CSS/JS | Debian 回环及 guest 地址、Windows localhost 与本机连接映射测试全部 200，12 项资源内容哈希匹配 | 本机分层内容成立，不代表其他 LAN 设备可访问 |
| HTTPS 页面/CSS/JS | 同样 12 项资源内容哈希匹配；客户端显式校验工作区 CA | 覆盖 guest/回环与按 Windows IP 校验的无 SNI 连接；Windows IP 的连接实际映射到 localhost，已明确标记 |
| 不信任 CA 的反向验证 | Debian 不指定 CA 时证书链校验失败 | 未用 `--insecure` 或关闭证书验证制造通过 |
| 非回环管理鉴权 | Debian guest 地址与保留 Windows Host 的本机连接映射请求：无 token 为 401，有效 token 为 200 | 非回环 Host/来源组合的已测行为 |
| 伪造回环头 | Debian 从 guest 地址请求时伪造 Host/XFF 仍为 401；Windows 实际连接 localhost 且将 Host 改为回环时为 200，符合现有本机免 token 路径 | 后一种是本机观测，不能写成经真实外部转发的身份验收通过；独立 LAN 转发后的反向测试仍待可达入口 |
| HTTPS 明文收敛 | 设置测试实例 `instanceBindHost=127.0.0.1` 并重启后，guest 地址的 HTTP 别名口、实例明文口、管理后端口均拒绝连接，HTTPS 仍正常 | 核验 Linux 监听与资源访问，未把外部超时当作已收敛证明 |
| 测试实例/网关恢复 | 实例 restart、网关 off/on 均成功，随后三个资源仍为 200 且内容匹配，CA 不变 | 仅为产品进程恢复，未执行 WSL/Windows 重启或休眠 |
| 独立 Mac 的 HTTP LAN 直连 | 三个测试端口 TCP 均未连通，页面未取得 | 独立观察点的失败，未获 LAN 正向通过证据 |
| 独立 Mac 的 HTTPS LAN 直连 | 两个 HTTPS 及三个明文测试端口均未连通 | 与网页映射缺失相符；不能单凭超时把根因唯一归为某一条防火墙规则 |
| 真实浏览器 JS 交互 | Codex 内置 Chromium 浏览器显示样例页面；按钮连续点击由0变为1再变为2，AX与截图留证 | 通过临时仅回环SSH通道读取测试实例，证明确实执行JS；不证明普通LAN入口、HTTPS浏览器系统信任或真实应用业务 |
| 本地项目回归 | `bash tests/gate.sh` 退出 0；Ruff、pytest、工作区与暂存区差异检查全部通过 | 包含现有 BUG-949/950 待提交修复；模拟/回归不填作新增实机组合 |

测试完已停止本次实例、网关和管理进程，五个测试端口均释放，浏览器验证使用的临时SSH回环端口和页面也已关闭。两套既有工作区配置哈希及既有运行容器名单与验收前一致。Windows 转发规则未修改；隔离源码和证据保留，便于后续续验。
