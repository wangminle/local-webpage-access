# BUG-1023、BUG-1024 修复记录

日期：2026-11-06。状态：两项修复、专项回归、最终完整门禁及独立复审均已完成；真实服务迁移／冷启动与显式端到端验收仍不在本轮证明范围。

## 修复行为

### BUG-1023：迁移恢复的服务范围

`workspace_migrate.restore_instances()` 不再全局启用所有已安装单元。启用范围为“当前配置允许、迁移快照已记录、当前明确归属本工作区”三个集合的交集；没有交集时不调用 enable。`autostart.enable()` 本身的显式管理语义保持不变。

因此 builtin 配置下，repair 重写并停用的旧 gateway 不会在 RESTORE 阶段再次加载；关闭的 manager 同样保持停用。正向迁移和回滚共用该恢复逻辑。

### BUG-1024：反引号命令替换上下文

`hosting._split_shell_and_segments()` 为反引号内容设置独立扫描状态，保留原文，正确跳过转义字符。内部引号、括号、`$()` 和 `&&` 不改变外层引号或命令替换状态；反引号结束后继续扫描外层命令。

以下原复现现在能够拆出顶层 pnpm，并沿用安装阶段的 corepack 版本钉定：

```sh
echo "`printf "'"`" && pnpm run build
```

测试还覆盖转义反引号、旧式嵌套反引号及与 `$()` 的组合。
