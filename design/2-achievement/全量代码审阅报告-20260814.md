## 三、候选疑点汇总（约 90 个，按组，尚未逐条独立确认）

> **口径说明（CHK-208 校正）：** 「约 90」不是可审计的精确缺陷数，而是分组审阅产出的**候选疑点**计数；原始分组报告中混有「不确定」「设计权衡」、已撤销项，以及被原报告标为 major 视觉级的前端弹窗问题。需逐条独立确认后方可定为缺陷。

完整逐条见 `_review_reports/group1~9-*.md`。重点（用户可见/安全相关）摘录：

- **前端**（组 9，8 条）：C.R03 降级确认弹窗类名错配（`.modal-card` 系列在 style.css 不存在，弹窗几乎不可读，major-视觉级）；`--font-mono` 未定义（笔误 `--monospace`）；token 失效后轮询不停止重复弹 toast；refresh 无竞态令牌；Escape 不关 fallbackDialog；cancel_failed 死分支。
- **安全审计**（组 7）：`security.py:432` ADD 远程 URL 检测大小写可绕过（`ADD HTTPS://…` 漏检 critical）；`./${VAR}` bind 源只 warn；配置未知键静默忽略。
- **API**（组 4）：`bool(payload.get("dryRun"))` 对字符串 `"false"` 判 True；`fallback_policy` 无枚举校验（typo 静默自动降级）；批量 `/api/redundant/remove` 无 confirmId 门禁（与单实例不一致）；DNS rebinding 无 Host 校验（加固缺口）。
- **诊断**（组 5）：doctor 端口池探测与分配器口径漂移（TIME_WAIT 误报 FAIL）；`_default_runner` 只捕 FileNotFoundError/TimeoutExpired；`MemAvailable` 缺失误报 FAIL；实例诊断 `reg.open()` 会创建 DB（违背只读）；SQLite data mount 整体缺失不告警。
- **数据层**（组 7）：`lwa.status` logger 不在命名空间（warning 不落日志文件）；ID/别名正则 `$` 接受结尾换行；`init_db` 失败路径锁泄漏；COMMIT 失败时 ROLLBACK 掩盖原异常；`models.save` 非原子写；pageviews 游标清理 LIKE 未转义（ID 校验不允许 `_/%`，实际不可利用）。
- **导入管线**（组 1，16 条）：`bun.lockb` 映射成 `npm ci` 必失败；子目录候选把"有依赖"当"有锁文件"决定 `npm ci`；preflight CHK-V02 单引号拆碎命令；`zf.extract` 异常未包装；workspaces glob 只展开首个 `*`；`sqlite:///C:/…` 盘符误判相对路径。
- **托管/构建**（组 2/3）：host_container up 后写盘失败留孤儿容器；`_enable_static` 成功后写失败端口泄漏；`start_container` 幽灵端口；docker build 超时不收尾 builds 行（管理页永久"进行中"）；`_reclaim_dead` 在写事务内 kill（长持锁）；cancel_build 对首次 start 构建 no-op；compose 值原样内插 YAML 未校验。
- **pageviews**（组 8）：日志被无归档方式截断（copytruncate）时游标不重置→永久漏计；别名根路径带 query 不归属；Caddy `ts` 非数值回退 now_iso 导致分桶漂移。
- **迁移/升级**（组 6）：verify 失败后 `--resume` 直接报成功不复验；`rewrite_manifest_paths` 恒返回 True；dry-run 动作清单与实际不一致；rollback 后残留迁移锁；`updater.run_access_pass` 是唯一未包 try/except 的步骤；预发布版本（`2.40.2-rc1`）可通过最低版本门禁。
