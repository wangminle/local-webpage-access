# 局域网部署安全测试：类型化结论（2026-07-30）

本文件保留历史测试的通用方法与结论。真实目标、主机名、地址、账号、逐项响应、操作脚本及详细现场分析仅存本地检查点；整理公开版本不表示重新执行测试。

## 范围与观察

测试对象是用户授权的局域网 LWA 部署，包括 Caddy 静态网关、带 token 鉴权的管理 API 和 ZIP 导入链。客户端从独立 LAN 设备发起请求。

| 测试类别 | 历史覆盖 | 已记录的结果 |
| --- | --- | --- |
| 阶梯负载 | 7 档，从 10 到 640 请求/秒 | 当次所有档位记录为请求成功，没有超时或异常恢复观察；不能据此推导其他硬件、业务或持续压力下的容量 |
| Web 攻击面探针 | 5 类，共 19 个探针 | 路径穿越、敏感文件、异常方法、未授权访问及响应注入类探针未在该测试集内获取目标敏感内容 |
| ZIP 导入 | 路径穿越、符号链接、压缩炸弹 3 类 | 被安全检查拒绝，未记录文件逃逸或残留实例 |

测试期间发现浏览量统计的两项功能问题：别名静态实例的直连端口漏计（BUG-415），以及 Caddy 特定滚动日志归档格式未被识别（BUG-416）。历史记录包含修复与回归；最新状态见 [任务台账](../../task-list.md)。

## 可复用的验收原则

- 同时覆盖网关、管理鉴权与导入隔离，不能用网关首页返回 200 代替三个边界的验证。
- 压测先冻结业务、运行时和资源预算，记录负载、成功率及延迟；速率只是测试条件，不是产品容量承诺。
- 拒绝结果须核对文件与实例状态，不能只看错误提示；ZIP 测试使用自建、可丢弃样本。
- 访问统计要分别验证别名与直连入口，以及日志滚动前后的补读，不把统计缺陷直接归类为安全突破。
- 测试结束按清单检查临时数据与进程，保留清理证据；公开报告只描述可核验的范围。

## 结论限制

本次有限探针未发现所测边界被突破，不能等同“没有漏洞”或持续安全认证。历史报告不足以代表当前版本、其他部署配置、应用自身安全或 HTTPS 信任链。明文传输、应用注册/限速、端口收敛及 Agent 身份仍须单独评估，设计背景见 [LAN 与 Agent 访问安全加固方案](../3-plans/2026-09-16-LAN与Agent访问安全加固方案.md)。
